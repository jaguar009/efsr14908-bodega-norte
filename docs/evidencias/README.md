# Evidencias del proyecto

## Entrega final

- `validacion_final_2026-10-11.json`: 17 casos HTTP en Kestrel y PostgreSQL real con esquemas desechables. Auth e IBM usan respuestas simuladas. Incluye limpieza y comparación de la base principal antes y después.
- `validacion_watson_2026-10-11.json`: ocho consultas y respuestas obtenidas de la instancia IBM real, publicada en Live, con plan Trial gratuito.
- `final_2026-10-11/validacion_interfaz.json`: once recorridos automatizados en Chrome con contextos nuevos, datos ficticios y vistas de escritorio y móvil; cero errores y advertencias.
- `final_2026-10-11/pruebas_dominio.txt`: 25 pruebas JavaScript aprobadas.
- `final_2026-10-11/01_inicio.png` a `14_ayuda_local.png`: 14 capturas originales a color de la demostración aislada. La última captura muestra ayuda local, no una respuesta IBM.
- `despliegue_final_2026-10-11.json`: readiness HTTP 200, rechazo HTTP 401 en rutas privadas sin sesión y CORS permitido para GitHub Pages.
- `../word/Anexo_Validacion_Final_Grupo10.docx`: explicación de los registros y las capturas en Word. La matriz y los manuales también se entregan en Word.

La prueba Java se ejecutó contra el servidor de pruebas y forma parte de los 17 casos del backend. Estas validaciones técnicas no acreditan aceptación de un comercio real, participación individual, firmas ni horas de asistencia. El Excel conserva avances propuestos.

## Registros históricos

`validacion_tecnica_2026-09-28.md` corresponde a la versión histórica SQL Server; `validacion_tecnica_2026-10-04.md` registra el incremento anterior. Las capturas `EVID_visual_escritorio.png` y `EVID_visual_movil.png` son referencias anteriores y no sustituyen los registros finales.
