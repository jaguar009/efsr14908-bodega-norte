# Manual de usuario

El manual final editable está en docs/word/05_Manual_Usuario.docx. Cubre ingreso, recuperación de contraseña, productos, venta, inventario, anulaciones, proveedores, reportes, permisos, respaldo y asistentes.

La demo guarda datos ficticios y simula roles. La web compartida requiere una cuenta confirmada y habilitada. El cajero consulta y registra ventas; el administrador gestiona cambios, anulaciones y respaldo. La constancia es interna y los medios de pago no ejecutan transferencias.

La ayuda local consulta los datos disponibles. IBM Watson explica tareas operativas en español y no ejecuta operaciones. Su Trial es gratuito por 30 días; la ayuda local sigue disponible de forma independiente.
